# Telegram Favorite Code

Author: Vlad Toropov
Group: M3107

VS Code extension to send selected code to Telegram Desktop.

## Features

- Send selected code to Telegram via hotkey Ctrl+Shift+T
- Uses clipboard if no text selected
- Opens Telegram Desktop with pre-filled message

## Installation

- Copy files to a new folder
- Run npm install -g @vscode/vsce using terminal
- Run vsce package using terminel
- Install the generated .vsix file in VS Code

## Usage

- Use Ctrl+Shift+T to send code
