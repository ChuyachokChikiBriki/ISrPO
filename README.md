# Geometric Library

A simple Python library for calculating areas and perimeters of various geometric shapes.

## Description

This library provides basic geometric calculations. It is designed for educational purposes and simplicity.

![image](cover.jpg)

## Functions

### Circle (`circle.py`)

- <span style="color:red">**`area(r)`**</span>
  - Calculates the area of a circle.
  - Parameters: `r` (radius).
  - Example: `area(3)` returns `28.274333882308138`.

- <span style="color:red">**`perimeter(r)`**</span>
  - Calculates the circumference of a circle.
  - Parameters: `r` (radius).
  - Example: `perimeter(3)` returns `18.84955592153876`.

### Square (`square.py`)

- <span style="color:red">**`area(a)`**</span>
  - Calculates the area of a square.
  - Parameters: `a` (side length).
  - Example: `area(5)` returns `25`.

- <span style="color:red">**`perimeter(a)`**</span>
  - Calculates the perimeter of a square.
  - Parameters: `a` (side length).
  - Example: `perimeter(5)` returns `20`.

### Rectangle (`rectangle.py`)

- <span style="color:red">**`area(a, b)`**</span>
  - Calculates the area of a rectangle.
  - Parameters: `a` (length), `b` (width).
  - Example: `area(4, 5)` returns `20`.

- <span style="color:red">**`perimeter(a, b)`**</span>
  - Calculates the perimeter of a rectangle.
  - Parameters: `a` (length), `b` (width).
  - Example: `perimeter(4, 5)` returns `18`.

### Triangle (`triangle.py`)

- <span style="color:red">**`area(a, h)`**</span>
  - Calculates the area of a triangle.
  - Parameters: `a` (base), `h` (height).
  - Example: `area(6, 4)` returns `12.0`.

- <span style="color:red">**`perimeter(a, b, c)`**</span>
  - Calculates the perimeter of a triangle.
  - Parameters: `a, b, c` (side lengths).
  - Example: `perimeter(3, 4, 5)` returns `12`.
